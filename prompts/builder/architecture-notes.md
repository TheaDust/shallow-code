## ARCHITECTURE.md 交接约定

在项目根维护 ARCHITECTURE.md，作为新会话定位代码和识别跨模块约束的短索引。默认目标不超过 8 KiB；最多 200 行且不超过 16 KiB，按实际 UTF-8 字节数计算。只保留能减少后续查找或避免破坏既有行为的信息。

开始工作时先读索引，再按路径与符号核对本包相关代码；需求与平台合同决定目标行为。已有应用代码而笔记缺失时建立首版；实现或修复改变已有约定时，原位更新相关条目并删除过时描述，没有变化时保持不动。

按实际需要保留下列信息，省略空项，标题和布局自行选择：

- **修改入口**：按领域或共享能力给出项目相对路径、简短职责和至多 1–3 个关键符号。每项用一到两句；需要同时修改的调用方、测试或 mock 在同一项点出。复杂模块只指向入口和权威定义。
- **关键约束**：只记单个文件难以说明、且跨模块修改必须保留的事实，例如权威状态与派生值的分工、持久化边界、原子性、权限判断位置或同步关系。一条约束写一次，附源码位置；必要时用一句解释原因。
- **必要准备**：给出种子定义位置、初始化时机，以及互斥初态或对象归属确实需要说明的公开准备路径。同类准备合并记录。影响续做的当前限制简述位置和影响，解决后删除。

字段全集、逐条 API、控件文案、算法步骤、测试用例清单和常规命令以源码、测试与 package.json 为准，索引只给定位入口。同一事实只保留一处；任务进度和本次检查结果写入回执。长表格单元格和超长行同样占用内容预算。

### 交接完成条件

本文新增或修改后，核对相关路径、符号和事实，并执行以下大小检查（在项目根运行）：

```sh
node -e "const fs=require('node:fs'); const text=fs.readFileSync('ARCHITECTURE.md','utf8'); const bytes=Buffer.byteLength(text,'utf8'); const lines=text.split(/\r?\n/).length; console.log({bytes,lines}); if(bytes>16384||lines>200) process.exit(1);"
```

超过 8 KiB 时先去重、合并同类条目，将可查细节替换为源码指针；超过硬上限必须继续压缩并复测，不能仅以行数或字符数判断大小。回执的“检查”项报告实测字节数与行数；只有确需保留的独立跨模块约束才使用 8–16 KiB 的空间。
