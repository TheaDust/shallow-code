## Web 开发检查

按当前改动选择局部检查。已有 DOM 或接口测试能回答的问题复用其结果；需要确认计算样式、原生焦点或尚未确认的真实交互时，再使用 browser。公共组件或导航改动只检查受影响的调用方和入口。

检查交互时，从需求规定的身份与公开入口进入，按需求核对全局控件的作用域、角色、可访问名、label、placeholder 和目标对象身份。等待实际就绪条件；刷新、身份变化、失败保留与下载内容只按本包涉及的要求检查。

browser 启动真实浏览器，属于昂贵操作，仅用于现有检查尚未回答的具体问题。先构建，再用 app start 等待健康检查并取得 baseUrl；重建前 stop，构建后重启，结束时 stop。browser 的 code 是直接执行的函数体，page/context/expect 已注入；通过实际断言判断结果，截图按视觉核对需要请求。

修复时，precondition 表示准备未完成，locator 表示定位尚需诊断，不能据此认定目标业务失败。先核对原文、页面状态、对象归属和公开准备路径；失败定位器的角色不自动成为实现要求。重复控件按需求中的容器和完整身份区分，不得为消除定位歧义而随意重命名、隐藏或删除；证实实现与需求冲突后再修正。
