# 可访问 Web 交互

先按需求确定控件的用途、角色、可访问名、容器和状态。文字与图示共同描述的交互按需求合同实现；未指定的结构使用符合用途的原生语义。操作用 button，页面导航用带 href 的 link；同名操作通过对应对象的单层容器区分。页面标题与同名导航链接分别保留其角色。

字段 label 关联输入，placeholder 独立实现。选择控件按需求决定使用原生 select 或支持搜索、建议与创建的 combobox，核对真实值、选择事件及可访问 option。使用项目已有组件；采用脚手架混合 Combobox 时，两种选择路径都须得到同一值，未展开的选项不造成其他控件的定位歧义。错误反馈、禁用状态和提交值按当前场景核对。

菜单触发器与弹出内容分别具名，角色和键盘操作符合各自用途。菜单选择后会卸载时，先完成项目路由导航再关闭菜单。导航方式沿用项目实现；需求规定地址表达状态时，核对默认状态、刷新与直接重开。

对话框有可访问名称，打开时管理焦点和背景交互，关闭后恢复合理焦点。需求要求关闭内容退出查询表面时，检查关闭分支的实际 DOM，并复查重开。管理型保存是否保留列表、表单是否关闭及失败保留什么，都按当前需求决定。

导航与字段结构只依赖已确认身份、路由和权限时，随目标视图呈现；确实依赖未就绪数据的操作保留忙碌和禁用状态。身份或对象变化后重新核对授权，避免旧内容与旧权限残留。

检查本包涉及的实际结果及其所属对象。通知使用适用的 status/alert，结果仍通过实际记录、输入、状态或数量核对。需求声明全局页头、导航或搜索时，检查其全局语义与作用范围；其余布局由产品需求和项目设计决定。
