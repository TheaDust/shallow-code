【仓库协作业务】
本包涉及的仓库、组织、分支、提交、议题、合并请求、评论和成员等对象应具有稳定标识、明确父对象和一致的权限关系。代码浏览、分支指向、提交历史、文件内容与差异应反映同一版本关系，变更后不能只更新其中一个视图。创建、编辑、关闭、删除或权限变更后，列表、详情、计数和刷新后的状态按需求保持一致。对象编号只在其规定的父级范围内唯一。不要为场景中的仓库名、分支名、对象编号或用户名建立硬编码结果。

对象可读性按需求中的拥有、组织关系和直接授权分别计算；有权读取的对象应能从该身份的规定列表、搜索或其他公开入口进入，不能把“可访问”缩成“个人拥有”。种子记录与入口同时核对：从场景规定的未登录或登录起点，沿允许的入口打开对象，确认完整身份、内容和本场景需要的操作权限。不可访问对象不暴露受保护内容；需求未规定首页直达时，保留其允许的列表或搜索路径。

场景以逐字标识符声明组织、仓库或工作项且没有另行声明入口显示名时，公开入口的可访问名保留该标识符；友好 display name 可以作为相邻说明或组合标题，但不能替换唯一可操作入口的需求名称。搜索结果、工作台列表、账户菜单后的组织列表使用同一稳定名称合同，不能让内部探针依赖代码自行发明的标题化别名。

本包实现组织或仓库功能且提供登录工作台时，工作台提供当前身份可见的组织和可读仓库的具名入口，同时保留需求规定的账户菜单、列表和搜索路径。按实际权限查询对象，同名对象按归属分组，每个对象在同组中保留一条入口。工作台首次呈现时，已登录身份与本页规定的具名对象入口一起就绪；身份或权限变化后重新核对列表，刷新仍能进入同一对象。组织、仓库及设置页的已授权导航控件随页面主体一起呈现，不能统一包在详情或列表加载成功的分支中；权限已确认且不依赖列表内容的创建入口也独立呈现。异步列表显示加载状态，确实依赖未就绪数据的操作待就绪后启用；后台继续校验每次读取和写入的权限。账户菜单到组织列表、安全设置、登出确认的各段入口均保持需求规定的角色、名称与容器，并核对点击后的目标页面或对话框。

站内菜单入口被选择后若菜单会立即关闭或卸载，先通过项目路由工具完成导航，再关闭菜单；不要依赖已卸载链接稍后发生的默认 hash 导航。普通站内 hash 链接沿用脚手架的同步导航桥接，保留修饰键、新窗口和非左键行为。对话框使用脚手架 Dialog，保留原生 dialog 语义及兼容类，不自行复制一套延迟开放的弹层。
